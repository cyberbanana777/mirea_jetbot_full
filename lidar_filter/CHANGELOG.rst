Changelog for package lidar_filter
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

1.1.0 (2026-10-16)
------------------
* Маска сектора считается один раз и пересчитывается только при изменении
  геометрии скана (число лучей, ``angle_min``, ``angle_increment``).
  Обработка скана стала примерно в 10 раз быстрее.
* Исправлено: ``header.stamp`` выходного скана теперь берётся из исходного
  скана, а не заменяется текущим временем. TF (AMCL, костмапы, SLAM)
  ищется на момент измерения.
* Исправлено: в ``filter.launch.py`` по умолчанию ``use_sim_time:=False``
  (было ``True``; на реальном роботе без ``/clock`` время было нулевым).
* **Изменение поведения** для разрывного сектора (``invert_sector:=True``
  или сектор через ±180°): раньше оставшиеся куски склеивались подряд,
  и углы части лучей получались неправильными. Теперь выкинутые лучи
  внутри диапазона заменяются на ``NaN``, а углы остальных лучей верны.
  Для сплошного сектора (по умолчанию -135°...135°) вывод не изменился.
* Нормализация углов через ``math.remainder`` вместо циклов ``while``;
  предупреждение о пустом секторе выводится не чаще раза в 5 с.
* Для работы на роботе рекомендуется ``lidar_filter_cpp``, этот пакет
  оставлен как запасной вариант (``use_cpp:=False``).
