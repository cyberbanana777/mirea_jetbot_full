# lidar_filter_cpp

C++-версия `lidar_filter`: фильтрует `sensor_msgs/LaserScan` по угловому
сектору. Параметры, топики и launch-файл такие же, как у Python-версии.

## Отличия от Python-версии

- маска сектора считается один раз и пересчитывается только при изменении
  геометрии скана (число лучей, `angle_min`, `angle_increment`); обработка
  скана сводится к копированию куска массива;
- `header.stamp` берётся из исходного скана (раньше подставлялось текущее
  время, из-за чего TF искался не на момент измерения);
- в `filter.launch.py` по умолчанию `use_sim_time:=False` (раньше было `True`,
  и на реальном роботе время было нулевым);
- **разрывный сектор** (`invert_sector:=True` или сектор через ±180°):
  выкинутые лучи внутри диапазона заменяются на `NaN`. Раньше оставшиеся
  куски склеивались подряд, и углы части лучей получались неправильными.
  Для обычного сплошного сектора (по умолчанию −135°…135°) результат
  такой же, как раньше: скан просто обрезается.

## Запуск

```bash
ros2 launch lidar_filter_cpp filter.launch.py start_angle_deg:=-135.0 end_angle_deg:=135.0
```

## Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `start_angle_deg` | `-135.0` | начало сектора, град |
| `end_angle_deg` | `135.0` | конец сектора, град |
| `invert_sector` | `false` | оставить всё, кроме сектора |
| `input_topic` | `/scan` | входной топик |
| `output_topic` | `/scan_filtered` | выходной топик |
| `output_frame_id` | `""` | frame_id выхода (пусто — как у входа) |
