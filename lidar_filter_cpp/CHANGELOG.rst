Changelog for package lidar_filter_cpp
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

1.0.0 (2026-10-25)
------------------
* Первая версия. C++-фильтр ``LaserScan`` по угловому сектору; заменяет
  Python-пакет ``lidar_filter`` (удалён). Параметры, топики, имя
  исполняемого файла (``lidar_filter``) и launch-файл (``filter.launch.py``)
  те же, меняется только имя пакета.
* Маска сектора считается один раз и пересчитывается только при изменении
  геометрии скана (число лучей, ``angle_min``, ``angle_increment``);
  обработка скана сводится к копированию куска массива.
* Исправлено по сравнению с Python-версией: ``header.stamp`` берётся из
  исходного скана, а не заменяется текущим временем, поэтому TF (AMCL,
  костмапы, SLAM) ищется на момент измерения. Из-за этого фильтру больше
  не нужен ``use_sim_time``: в ``filter.launch.py`` по умолчанию ``False``
  (было ``True``), в симуляции он работает и без этого аргумента.
* **Изменение поведения** для разрывного сектора (``invert_sector:=True``
  или сектор через ±180°): раньше оставшиеся куски склеивались подряд,
  и углы части лучей получались неправильными. Теперь выкинутые лучи
  внутри диапазона заменяются на ``NaN``, а углы остальных лучей верны.
  Для сплошного сектора (по умолчанию -135°...135°) вывод не изменился.
* Предупреждение о пустом секторе выводится не чаще раза в 5 с.
* Выходное сообщение публикуется через ``unique_ptr`` (без копирования
  при intra-process передаче).
* Узел зарегистрирован как компонент (``lidar_filter_cpp::LaserSectorFilter``).
* Юнит-тесты расчёта сектора (``test/test_sector.cpp``).
