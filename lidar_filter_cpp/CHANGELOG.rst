Changelog for package lidar_filter_cpp
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

1.0.0 (2026-10-16)
------------------
* Первая версия. C++-версия ``lidar_filter`` с теми же параметрами,
  топиками и launch-файлом (``filter.launch.py``).
* Маска сектора кэшируется по геометрии скана; исходный ``header.stamp``
  сохраняется; для разрывного сектора выкинутые лучи заменяются на ``NaN``
  (подробнее - в CHANGELOG ``lidar_filter`` 1.1.0).
* Выходное сообщение публикуется через ``unique_ptr`` (без копирования
  при intra-process передаче).
* Узел зарегистрирован как компонент (``lidar_filter_cpp::LaserSectorFilter``).
* Юнит-тесты расчёта сектора (``test/test_sector.cpp``).
