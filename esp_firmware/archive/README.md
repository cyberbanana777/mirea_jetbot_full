# Архив ESP32

Исторические материалы. **Ничего из этого каталога не собирается, не
подключается к тестам и не поддерживается.** Перенос выполнен в рамках
Этапа 5 (гигиена репозитория, риск R-08 в `../../docs/ai/project-state.md`).

| Каталог | Что это | Статус |
|---|---|---|
| `esp32_firmware_old/` | Первая, монолитная версия прошивки (5 файлов `.ino`, протокол v1) | Не собирается. Действующая прошивка — `../esp32_firmware/`, протокол v2 |
| `Speed_for_PID_test_speed/` | Отладочный скетч Arduino: детектор фронтов двухканального энкодера | Справочный характер; описание логики — в заголовке `.ino` |
| `Speed_for_PID_test_speed_with_ITR/` | То же с обработкой по прерываниям | То же |
| `reports/` | 11 прогонов `tools/uart_bench/hardware_suite.py` на реальном железе (2026-11-02), все PASS | Единственное в репозитории свидетельство прогонов на плане. **Версия прошивки в прогонах не зафиксирована** |

## Правила обращения с архивом

- Ни один файл из `archive/` не подключается к сборке: ни `Makefile`, ни
  `package.xml`, ни CI на них не ссылаются.
- Новые прогоны пишутся в `esp_firmware/reports/`; этот каталог в
  `.gitignore`, результаты в git не попадают. В `archive/reports/` файл
  переносится (`git mv`) только тогда, когда результат нужно сохранить как
  свидетельство; тогда же добавляется запись в
  `../docs/testing/HARDWARE_TEST_LOG.md` с указанием версии прошивки.
- История кода доступна в git. Отдельные `.diff`-файлы миграции v1 → v2
  (`changes.diff`, `changes_ladrc.diff`) удалены как дублирование журнала
  версий: они ссылались на каталоги `fw_orig/` и `v24/`, которых в
  репозитории нет.
